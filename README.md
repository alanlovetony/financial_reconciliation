# 财务对账工具 💰

一个基于 Streamlit 和 Pandas 开发的财务对账系统，用于对比业务系统数据与银行实际到账流水。

## 功能特点

- 📁 **简化上传**: 只需上传2个文件（有益云数据 + 银行流水）
- 🔄 **智能识别**: 自动根据捐赠说明区分 T+1 和 T+N 数据
- 📊 **可视化报告**: 绿色标记匹配项，红色标记未匹配项
- 💾 **导出功能**: 一键导出 Excel 格式对账报告
- 🎯 **T+N 支持**: 处理延迟到账的业务场景

## 安装步骤

1. 克隆或下载项目文件

2. 安装依赖包：
```bash
pip install -r requirements.txt
```

## 使用方法

1. 启动应用：
```bash
streamlit run financial_reconciliation.py
```

2. 在浏览器中打开显示的 URL (通常是 http://localhost:8501)

3. 上传两个数据文件：
   - **有益云数据**: 直接从有益云系统导出的 Excel/CSV 文件
   - **银行流水**: 银行导出的流水文件

4. 点击"开始对账"按钮

5. 查看对账结果并下载报告

## 数据格式要求

### 有益云数据
直接从有益云系统导出即可，系统会自动：
- 跳过第一行（汇总信息行）
- 根据 `捐赠说明` 字段自动识别 T+1 和 T+N：
  - **带【GFYH】** → T+N（广发银行收款通道）
  - **不带【GFYH】** → T+1（财付通收款通道）

必须包含的列：
| 捐赠项目 | 捐赠时间 | 捐赠金额 | 捐赠说明 |
|---------|---------|---------|---------|
| 项目A   | 2024-01-01 10:30:00 | 1000.00 | 【GFYH】微信捐款... |
| 项目B   | 2024-01-01 14:20:00 | 2000.00 | 【微信小程序】捐款... |

### 银行流水数据
| 发生时间 | 收入 | 用途 | 附言 |
|---------|------|------|------|
| 2024-01-03 | 3000.00 | 银联入账 | 0101_1573... |
| 2024-01-04 | 5000.00 | 收单入账 | 20240102至20240102... |

## 对账逻辑

1. **数据分类**: 根据捐赠说明中的【GFYH】标识自动区分 T+1 和 T+N
2. **T+1 匹配**: 银行到账日期 - 1天 = 业务日期（适用于财付通通道）
3. **T+N 匹配**: 从银行附言中提取业务日期（支持 MMDD 和 YYYYMMDD 格式）
4. **金额匹配**: 按日期汇总后进行金额匹配（允许0.01误差）
5. **结果输出**: 生成包含匹配状态、差异金额等信息的详细报告

## 输出报告字段

- **业务日期**: 原始业务发生日期
- **系统应收总额**: 该日期的应收总金额
- **系统笔数**: 交易笔数
- **匹配状态**: ✅ 匹配 / ⚠️ 银行多收 / ❌ 未匹配
- **银行到账日期**: 实际到账日期
- **银行实收金额**: 银行实际收入金额
- **银行摘要**: 银行流水的用途和附言
- **差异金额**: 系统金额与银行金额的差异
- **匹配来源**: T+1 或 T+N

## Excel 报告内容

导出的 Excel 报告包含以下工作表：
1. **对账汇总** - 按日期的对账结果
2. **项目明细(透视)** - 项目×日期的金额透视表
3. **银行流水** - 银行流水明细
4. **T+1明细** - T+1 类型的原始数据
5. **T+N明细** - T+N 类型的原始数据

## 注意事项

1. 有益云文件的第一行（汇总信息行）会被自动跳过
2. 银行流水中的收入列如果包含非数字值（如"-"）会被自动处理
3. 日期格式会自动解析，支持常见格式
4. 金额匹配允许 0.01 的误差
5. 建议先用小数据集测试

## 常见问题

**Q: 如何判断一条记录是 T+1 还是 T+N？**
A: 系统会检查 `捐赠说明` 字段：
- 包含 `【GFYH】` → T+N（广发银行广发易汇收款）
- 不包含 `【GFYH】` → T+1（其他收款渠道如微信小程序等）

**Q: 为什么有些记录没有匹配上？**
A: 可能原因：
- 金额不完全一致
- 银行到账日期与业务日期的关系不符合 T+1 或 T+N 规则
- 备注信息无法解析出业务日期

**Q: 如何提高匹配准确率？**
A: 
- 确保银行流水的附言或用途包含业务日期信息
- 检查金额是否完全一致
- 确认时间逻辑是否正确

**Q: 支持哪些文件格式？**
A: 支持 CSV、XLS、XLSX 格式
