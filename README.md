# 财务对账工具 💰

一个基于 Streamlit 和 Pandas 开发的财务对账系统，用于对比业务系统数据与银行实际到账流水。

## 功能特点

- 📁 **多文件上传**: 支持 CSV 和 Excel 格式
- 🔄 **智能匹配**: 基于金额、时间和备注信息的多维度匹配
- 📊 **可视化报告**: 绿色标记匹配项，红色标记未匹配项
- 💾 **导出功能**: 一键导出 Excel 格式对账报告
- 🎯 **T+N 支持**: 处理延迟到账的业务场景

## 安装步骤

1. 克隆或下载项目文件

2. 安装依赖包：
```bash
pip install -r requirements.txt
```

## 使用方法

1. 启动应用：
```bash
streamlit run financial_reconciliation.py
```

2. 在浏览器中打开显示的 URL (通常是 http://localhost:8501)

3. 上传三个数据文件：
   - **有益云 T+1 数据**: 包含列 `捐赠项目`, `捐赠时间`, `捐赠金额`
   - **有益云 T+N 数据**: 结构同上
   - **银行流水**: 包含列 `发生时间`, `收入`, `用途`, `附言`

4. 点击"开始对账"按钮

5. 查看对账结果并下载报告

## 数据格式要求

### 业务系统数据 (T+1 和 T+N)
| 捐赠项目 | 捐赠时间 | 捐赠金额 |
|---------|---------|---------|
| 项目A   | 2024-01-01 10:30:00 | 1000.00 |
| 项目B   | 2024-01-01 14:20:00 | 2000.00 |

### 银行流水数据
| 发生时间 | 收入 | 用途 | 附言 |
|---------|------|------|------|
| 2024-01-03 | 3000.00 | 捐款 | 0101_1573... |

## 对账逻辑

1. **数据聚合**: 将 T+1 和 T+N 数据按项目和日期汇总
2. **金额匹配**: 查找金额相同的银行流水记录
3. **时间验证**: 银行到账日期必须 >= 业务发生日期
4. **备注辅助**: 通过银行备注中的日期信息（如 "0101"）提高匹配准确度
5. **结果输出**: 生成包含匹配状态、差异金额等信息的详细报告

## 输出报告字段

- **项目名称**: 业务项目名称
- **业务发生日期**: 原始业务发生日期
- **系统应收总额**: 该日期该项目的应收总金额
- **系统笔数**: 交易笔数
- **匹配状态**: ✅ 匹配 / ❌ 未匹配
- **银行到账日期**: 实际到账日期
- **银行流水金额**: 银行实际收入金额
- **银行摘要**: 银行流水的用途和附言
- **差异金额**: 系统金额与银行金额的差异
- **时间差(天)**: 到账延迟天数

## 技术栈

- **Python 3.8+**
- **Streamlit**: Web UI 框架
- **Pandas**: 数据处理
- **NumPy**: 数值计算
- **OpenPyXL**: Excel 文件处理

## 注意事项

1. 确保上传的文件包含必需的列名
2. 日期格式会自动解析，支持常见格式
3. 金额匹配允许 0.01 的误差
4. 建议先用小数据集测试

## 常见问题

**Q: 为什么有些记录没有匹配上？**
A: 可能原因：
- 金额不完全一致
- 银行到账日期早于业务发生日期
- 备注信息不包含日期线索且时间差超过7天

**Q: 如何提高匹配准确率？**
A: 
- 确保银行流水的附言或用途包含业务日期信息（如 MMDD 格式）
- 检查金额是否完全一致
- 确认时间逻辑是否正确

**Q: 支持哪些文件格式？**
A: 支持 CSV、XLS、XLSX 格式
